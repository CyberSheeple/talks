# Talk title

- **When:** Month Year
- **Who:** presenter
- **Slides:** `slides.pdf`

Drop an exported Google Slides PDF here as `slides.pdf`. CI (or `npm run ingest`) writes `slides.md` for search.

Optional:

- `recap.md` — short writeup of what the talk covered. Not a reconstructed script of a live room.
- `transcript.md` — spoken words aligned to `## Slide N` headings. Use `npm run align` with captions when you have a recording.
